# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-22
- Migrated single-file PWA to Vite + React scaffold
- Extracted modules: `api`, `store`, `i18n`, `ui`
- Added runtime language switching and `LanguageSelector` component
- Implemented `server.js` proxy for Anthropic and USDA APIs
- Added service worker (`sw.js`) and `manifest.webmanifest`
- Split UI into components and improved accessibility
- Fixed build-time JSX errors and other minor bugs
